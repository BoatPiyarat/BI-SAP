# DRAFT — สอบถาม Aware เรื่องวิธี interface เพื่อลดงาน manual แก้ WHT (กลุ่มแชทใหญ่)

**สถานะ: ร่างเท่านั้น ยังไม่ได้ส่ง — รอ Boat ทบทวน/แก้ไข/อนุมัติก่อนส่งเอง**

---

สวัสดีค่ะทีม Aware

ก่อนหน้านี้ทางทีมได้แก้ไข script interface สำหรับกลุ่ม order onetime ที่บันทึกบัญชีผิดไปแล้ว (จากที่เคยเรียนไว้ก่อนหน้า) ตอนนี้ยอดหลักลง **1135-01 (AR Credit Card and Payment Gateway)** ถูกต้องแล้วเกือบทั้งหมด 🙏

แต่ยังพบว่ามีบาง order ที่ยอดหลักลงถูกบัญชีแล้ว แต่ **ยังมีส่วนต่างเล็กๆ (ระดับ WHT) ที่ยังต้องให้บัญชี manual adjust อยู่** อยากขอคำแนะนำวิธี interface ที่ถูกต้อง เพื่อให้ระบบบันทึกให้ครบตั้งแต่รอบแรก ไม่ต้องมาปรับปรุงทีหลังค่ะ

**ตัวอย่าง: OrderItem `L80580491-V2` (6 ส.ค. 2569)**

ยอดหลัก 5,549.84 ลง 1135-01 ถูกต้องแล้วค่ะ แต่ยอด WHT (55.14 บาท) กลับถูกบันทึก **2 ที่พร้อมกัน** — ทั้งที่ 2142-10 (ถูกต้องตามที่ควรจะเป็น) และ**ซ้ำอีกครั้งไปค้างที่ 1134-01 โดยไม่มีรายการมาหักล้าง** ทำให้บัญชี 1134-01 มียอดค้างสะสมที่ไม่ใช่ installment จริง ต้อง manual clear ทุกครั้งที่เจอเคสแบบนี้

ปัจจุบัน ExpectedReceived = 5,604.98 และ ActualReceived = 5,549.84 (ต่างกัน 55.14 ซึ่งตรงกับยอด WHT พอดี) — ทางทีมเข้าใจว่าส่วนต่างนี้เป็นเหตุให้ระบบ SAP บันทึกเข้า 1134-01 อีกรอบ ควบคู่ไปกับที่ลง 2142-10 อยู่แล้ว

ตรวจสอบเพิ่มเติมพบว่าช่วง 20-26 ส.ค. 2569 เพียงสัปดาห์เดียว มี order ลักษณะนี้อีก **23 รายการ** (ไม่นับกลุ่ม resubmit) ทุกรายการมียอดที่ 1134-01 เท่ากับยอดที่ 2142-10 เป๊ะทุกคู่ — ยืนยันว่าเป็น mechanism ที่เกิดซ้ำเป็นระบบทุกวัน ไม่ใช่ความผิดพลาดเฉพาะเคส และไม่ได้จำกัดแค่ channel EDC หรือลูกค้ากลุ่มใดกลุ่มหนึ่ง

จึงอยากรบกวนสอบถามค่ะว่า:
1. ในกรณีที่มีส่วนต่างจาก WHT แบบนี้ ทางทีมควรส่งค่าอะไรในไฟล์ interface (หรือปรับ field ไหน) เพื่อให้ระบบบันทึกยอด WHT เข้า **2142-10 บัญชีเดียว** โดยไม่ไปค้างซ้ำที่ 1134-01 คะ
2. มีวิธีทำให้ ExpectedReceived เท่ากับ ActualReceived ตั้งแต่ต้น (รวม WHT เข้าไปในสูตรคำนวณ) เพื่อให้เข้า flow ปกติเลยได้ไหมคะ หรือจำเป็นต้องมีส่วนต่างเสมอสำหรับ order ที่มี WHT
3. รายการที่ค้างอยู่ที่ 1134-01 จากลักษณะนี้ (ยังมีอยู่หลายสิบรายการ) จะให้บัญชี manual clear เอง หรือมีวิธี resubmit ให้ระบบเคลียร์ให้อัตโนมัติได้คะ

เป้าหมายคืออยากให้บัญชีไม่ต้อง manual adjust รายการ WHT เหล่านี้เลยค่ะ ขอบคุณมากค่ะ ยินดีส่งตัวอย่างเพิ่มเติมได้ตามต้องการเลยค่ะ
