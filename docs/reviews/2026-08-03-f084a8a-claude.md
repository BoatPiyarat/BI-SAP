## Note (non-blocking)

The 60-minute window is a *search* window computed from each poll's run time, not a *coverage*
guarantee — its correctness depends on the Apps Script trigger firing more often than every 60
minutes (with margin) so no result email ever ages out of every poll's lookback before being seen.
Neither this delta nor the runbook elsewhere in the file states that trigger cadence. Recommend
adding the trigger interval (or an explicit statement that it's out of scope / already enforced
elsewhere) before treating the one-hour bound as a closed gap — a poll gap longer than the window
would leave a genuine result permanently stuck at `PENDING_ACK` with no alert path described here.
