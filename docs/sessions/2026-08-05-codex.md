## Post-import refresh handoff design

private dispatcher. This is deliberately a Class-B design increment: it does not create the topic,
service, workflow mode, or a child execution. Its purpose is to keep mailbox and Pub/Sub retries
from creating duplicate Unit-1 mirror refreshes and to prevent the child path from running Units

## Private dispatcher source

Added `infra/post_import_dispatcher/` and a post-import mode in the existing Unit-1 workflow. The
Cloud Run source validates the minimal Pub/Sub event, claims by a deterministic exact-key token,
and creates a Workflows execution carrying only LogID/token. The workflow uses its built-in project,
location, workflow, and execution identifiers to construct the server-assigned full name and bind
it before any extract/load/mirror work. A duplicate losing execution returns without Unit 1; a
winner persists `SUCCEEDED`, stops after Unit 1, and cannot enter Units 2–5 or delivery. A later
watchdog increment must classify executions that terminate before success. Source only: no
deployment, IAM, topic, subscription, trigger, execution, GCS write, or SAP action.
