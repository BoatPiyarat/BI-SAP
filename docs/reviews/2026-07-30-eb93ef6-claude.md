Specific gap: the design does not describe what happens when an import-result email has a LogID in
its metadata but `getAttachments()` returns zero files (attachment missing/stripped/delayed). Given
this project's own recorded failure pattern ("silent drops are the #1 historical bug class"), an
explicit fallback (e.g. insert the header row with `status='ATTACHMENT_MISSING'` rather than
silently skipping) would close this before implementation, not after a real incident.

Marking PASS WITH NOTES rather than BLOCK: this is a design doc, not a deployed object, and the gap
is addressable during SQL-domain implementation without revising the design's core structure.
